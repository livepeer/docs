# Feature Catalogue

Every feature this repo offers. The input for accurate, up-to-date content writing.

A "feature" is any capability the user can:
- **Read about** — documented page, tutorial, reference
- **Discover via** — search, navigation, redirect, sitemap
- **Use through** — UI component, snippet, script, automation
- **Trigger** — workflow, hook, dispatch

## Vocabulary

| Audience | Tag |
|---|---|
| Developer (API consumers) | `dev` |
| Gateway operator | `gateway-op` |
| Orchestrator operator | `orch-op` |
| Delegator | `deleg` |
| Reader (about, community) | `reader` |
| Repo contributor / maintainer | `contrib` |
| Internal (Livepeer team) | `internal` |

| Maturity | Tag |
|---|---|
| `shipped` | Live in production, documented, stable |
| `beta` | Live but flagged or unstable docs |
| `alpha` | Experimental, not user-facing |
| `planned` | Documented as future, not yet built |
| `deprecated` | Documented but slated for removal |
| `undocumented` | Exists in code/infra but no docs page |
