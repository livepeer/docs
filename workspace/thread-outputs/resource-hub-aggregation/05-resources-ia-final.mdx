The Resource HUB lives at the `v2/resources/` namespace (matches existing canonical content: glossary, help-center, changelog/, concepts/, compendium/, documentation-guide/).

Each HUB nav leaf is shown as a **folder** containing the source files that produce its content. Per direction: *"the page of the Tree that represents the final mdx that will live there should be a folder for the content that is used to produce it."*

Audience tabs are NOT modified. Audience-specific pages (gateway FAQ, delegator videos, orchestrator pools) remain in their audience tabs. The HUB lists CANONICAL pages — either composable wrappers (for pure duplicates) or hand-authored aggregations (for content collated from multiple audience sources).

## Legend

| Marker | Meaning |
|---|---|
| 📂 → 📄 | Final HUB MDX page (shown as folder containing its sources) |
| ⚙️ composable | Pure-duplicate — content lives in `snippets/composables/`, multiple wrappers import it |
| ➕ aggregation | New hand-authored canonical that combines content from N audience-tab pages |
| ✅ exists | Canonical page already in place — no work needed |
| 🆕 new | New file to create |
| 🔁 wrap | Existing audience page converted to a wrapper that imports the canonical composable |
| ⏸️ deferred | Generated content (AI-API, CLI-HTTP, SDK changelogs) — handling TBD |
