## What this plan covers

File system operations, `docs.json` navigation updates, and internal link fixes that change the structure of the section without requiring content writing. Written to be **directly executable by a coding agent** — every operation is explicit with source, destination, and any downstream link updates required.

**Prerequisites:**
- Plan 1 (low-hanging fruit) must be complete — particularly the dead file deletions and the `artibtrum` rename
- Plan 2 (content tasks) for `about-gateways/overview.mdx` must be complete before the consolidation delete in Section 2

**Do not run Section 6 (publish/ deletion) until confirming no external links point to those URLs.**

## 1. Create `future/` holding folder

Some pages are not ready to ship but contain useful planning material. Rather than deleting them, move to a folder that is not surfaced in the sidebar navigation.

### Operations

```bash
# Create the folder
mkdir -p v2/gateways/future

# Move files
mv v2/gateways/run-a-gateway/build-options.mdx \
   v2/gateways/future/build-options.mdx

mv v2/gateways/run-a-gateway/gateway-operator-opportunities.mdx \
   v2/gateways/future/gateway-operator-opportunities.mdx
```

### docs.json update

Remove both pages from the navigation entirely. The `future/` folder should **not** appear in the sidebar. These files are retained for reference only.

```json
// REMOVE from docs.json navigation (wherever they currently appear):
"run-a-gateway/build-options",
"run-a-gateway/gateway-operator-opportunities"
```

### Internal link audit

```bash
# Check for any internal links to these pages
grep -r "build-options" v2/ --include="*.mdx"
grep -r "gateway-operator-opportunities" v2/ --include="*.mdx"
```

If any links are found, update them to point to `run-a-gateway/why-run-a-gateway` (the closest equivalent content that will remain in the live IA).
