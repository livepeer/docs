# Orchestrator Quickstart

Livepeer orchestrators can serve three types of workloads. Choose the one that matches your hardware and goals.

<Callout type="info">
Not sure which job type to run? Read the [Job Types overview](/v2/orchestrators/about-orchestrators/job-types) for a comparison of hardware requirements, payment mechanics, and current demand levels.
</Callout>

<CardGroup cols={3}>
  <Card
    title="Realtime AI"
    icon="bolt"
    href="/v2/orchestrators/quickstart/realtime-ai"
  >
    **Recommended for new operators.** Serve live AI inference workloads (live-video-to-video, real-time pipelines). Requires an NVIDIA GPU. Current highest-demand job type with active protocol development.
  </Card>
  <Card
    title="Transcoding"
    icon="film"
    href="/v2/orchestrators/quickstart/transcoding"
  >
    Serve video transcoding (HLS, WebRTC) using CPU-primary infrastructure. Lowest hardware barrier to entry. Note: transcoding is in a legacy maintenance trajectory.
  </Card>
  <Card
    title="Batch AI"
    icon="layer-group"
    href="/v2/orchestrators/quickstart/batch-ai"
  >
    Serve async AI inference jobs (image generation, audio transcription, LLM). Requires an NVIDIA GPU. Payment mechanics and formal protocol support are in active development.
  </Card>
</CardGroup>
