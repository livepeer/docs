# Experiment: optional backend demo

**AI assistant test (main):** Run `mint dev`, open **Home → Test**, use the **chat button** in the docs. That tests the Mintlify AI assistant. See `docs/PLAN/11-mintlify-ai-investigation.md`.

---

This folder is an **optional** demo: a small server that asks for a name and appends it to `names.txt`. Not required for testing the assistant.

```bash
cd docs/experiment && node server.js
# Open http://localhost:3765
```

Files: `server.js`, `index.html`, `names.txt`.
