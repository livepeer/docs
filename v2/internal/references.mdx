## Repositories

| Repository | Role |
| --- | --- |
| `livepeer/docs` | This repository. Branch `docs-v2` deploys to docs.livepeer.org via Mintlify. Working branch `docs-v2-dev`. |
| `livepeer/protocol` | On-chain smart contracts (bonding, rewards, fees, ticket redemption). Source of truth for contract addresses and ABIs. |
| `livepeer/go-livepeer` | Reference Orchestrator + Gateway binary. Source of release tags consumed by `snippets/data/globals/latestRelease.jsx`. |
| `livepeer/ai-runner` | AI worker runtime. Source of OpenAPI specs for AI Worker and AI Gateway under `api/`. |
| `livepeer/ai-worker` | AI job submission layer. |
| `livepeer/livepeer.js`, `livepeer/livepeer-go`, `livepeer/livepeer-python` | Official SDKs documented under `v2/resources/changelog/apis-sdks/`. |
| `livepeer/governor-scripts` | Authority manifest for the contract addresses pipeline. |
| `livepeer/explorer` | On-chain explorer; referenced from Delegator and Orchestrator pages. |
| `livepeer/subgraph` | The Graph subgraph; referenced from protocol and Delegator pages. |
