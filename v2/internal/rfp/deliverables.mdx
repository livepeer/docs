This page is the deliverables index. The full audited deliverable matrix with status (Completed / Partial / Blocked / Cancelled), notes, and evidence per line item lives in [RFP Report](/v2/internal/rfp/report). The long-form work audit is at `v2/internal/rfp/reports/livepeer-docs-v2-report.md`.

## The four RFP deliverable buckets

### (i) Documentation Strategy

> "Create a new outline for Livepeer documentation, including full map of current documentation, a clear information architecture and timeline for writing new documents." – RFP, September 2024

What was contracted: stakeholder identification, audit of v1 with deprecation recommendations, persona definitions, IA design, platform evaluation, content writing timeline.

Where the detail lives: [RFP Report](/v2/internal/rfp/report) section (i); long-form audit Parts 3.1–3.3.

Current state: Completed.

### (ii) Content Rewrites

> "Rewrite the documentation across the agreed information architecture."

What was contracted: rewritten pages under the new IA, accurate against current Livepeer surfaces.

Where the detail lives: [RFP Report](/v2/internal/rfp/report) section (ii); long-form audit Part 5.

Current state: Completed in shape, refinement ongoing. All 10 v2 tabs published. Gateways verify / monitor / connect threads built or shipping. 307-row cleanup matrix tracks remaining `_workspace` and `x-deprecated` lane work; not a content gap.

### (iii) Deliver v1 documentation live with redirects, SEO / AEO / WCAG / analytics / i18n

> "Deliver v1 documentation live with redirects, SEO and AEO optimisation, WCAG accessibility, analytics tracking, and internationalisation."

What was contracted: v1 preserved and live, version switcher, redirects for renamed routes, SEO optimisation, AEO readiness, WCAG accessibility, analytics, multilingual readiness.

Where the detail lives: [RFP Report](/v2/internal/rfp/report) section (iii); long-form audit Part 6.

Current state: Mostly complete with named partial items.

- v1 live with version switcher: delivered.
- Redirects: delivered for renamed routes.
- SEO: delivered; generator expanded; manual-only flag remains on `generate-seo.js`.
- AEO: partial; `llms.txt`, AI-enriched sitemap, hosted MCP delivered; no CI gate on regeneration yet.
- WCAG: audited and partially repaired via the Styles Governance pipeline; focus-visible + responsive CSS shipped.
- Analytics: partial.
- i18n: switcher live; no published translations.

### (iv) Public maintenance workflow

> "Establish a public maintenance workflow: style guide, contribution workflow, ownership handoff, and ticketing."

What was contracted: published style guide, contribution workflow, ownership handover, ticketing intake.

Where the detail lives: [RFP Report](/v2/internal/rfp/report) section (iv); long-form audit Parts 7–8.

Current state: Substantially advanced beyond the original RFP commitment.

- Style guide: live and enforced through the Styles Governance pipeline.
- Contribution workflow: live; extended with agent governance and native AI adapter documentation.
- Ownership handover: ownerless governance model published; CODEOWNERS preserved; decision registry added; D-DG-01..13 lock the docs-guide structure.
- Ticketing: 8 issue templates with auto-label, auto-assign, and Discord intake pipeline.

## Beyond-scope work delivered after handover

Material work shipped after the February 2026 audit deadline that the RFP did not commission. See [Outcomes](/v2/internal/rfp/outcomes) for the full list. Headline items:

- Self-remediating ownerless governance spine (13 frameworks, 18 policies, 5 standards).
- 34 canonical AI skills + 6 native agent adapters.
- `lpd` CLI as the unified contributor entry point.
- 4 in-repo VS Code extensions including custom MDX preview.
- Asset Pipeline + Changelog Pipeline.
- Contracts pipeline gold-standard (daily cron + shadow verification + bytecode auth).
