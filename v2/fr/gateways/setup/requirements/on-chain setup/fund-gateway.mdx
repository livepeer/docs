# Ajouter des fonds au portefeuille du Gateway
</div>

Pour exploiter le Gateway en production, vous devez avoir de l'Ethereum sur la Blockchain L2 [Arbitrum One](https://arbitrum.io/) - c'est là que les contrats intelligents de Livepeer sont déployés et qui fournit la couche de paiement pour Livepeer.

<Callout icon="question-circle" color="#2d9a67">
 Pas natif du Web3 ?
  <Expandable title="Explication rapide d'Arbitrum">
 Chaque blockchain fonctionne comme son propre réseau et utilise sa propre monnaie.
 Ethereum est la monnaie du réseau L1 Ethereum et Arbitrum ETH est la
 monnaie du réseau L2 Arbitrum. Arbitrum est une solution de mise à l'échelle pour le
 réseau Ethereum - il fonctionne en regroupant les transactions et en les traitant
 hors chaîne, puis en les réconciliant avec le réseau principal Ethereum, un peu comme un
 magasin qui totalise toutes ses ventes chaque jour et réconcilie ses reçus.
 Cela rend les transactions sur Arbitrum beaucoup moins chères que sur Ethereum, tout en
 fournissant la sécurité et la confiance du réseau Ethereum.
  </Expandable>
</Callout>

<Info>
 _Si vous avez de l'ETH sur le réseau L2 d'Arbitrum, vous pouvez simplement transférer les fonds
 vers le compte ETH du Gateway nouvellement créé._
</Info>

  <StyledStep title="Pont vers Arbitrum" titleSize="h2">
    <Info>
 _Livepeer fonctionne sur le réseau L2 d'Arbitrum et nécessite que les fonds soient
 pontés._
    </Info>
 Vous pouvez envoyer de l'ETH à votre adresse de Gateway sur Ethereum Mainnet puis le ponter vers le réseau L2 d'Arbitrum.

 Consultez le [Guide de pont Arbitrum](https://docs.arbitrum.io/arbitrum-bridge/quickstart)

    <iframe src="https://docs.arbitrum.io/arbitrum-bridge/quickstart" height="600px" width="100%" title="Embedded content from docs.arbitrum.io" />

  </StyledStep>
  <StyledStep title="Déposer sur le Gateway" titleSize="h2">
 <Note>Vous pouvez le faire à l'étape précédente en envoyant simplement l'Arbitrum ETH à votre adresse de Gateway.</Note>

 Une fois que vous avez de l'ETH sur le réseau Arbitrum, transférez-le vers votre adresse
 de Gateway nouvellement créée.

  </StyledStep>
  <StyledStep title="Configurer la réserve du Gateway et déposer les fonds" titleSize="h2">
 Nous devons maintenant diviser les fonds du Gateway en un **Dépôt** et une **Réserve**

    <Note>
 Le processus de dépôt nécessite :
    - Le Gateway fonctionnant en mode on-chain (pas offchain)
    - Suffisamment d'ETH dans votre portefeuille pour le dépôt + frais de gas
    - La CLI connectée au port HTTP de votre gateway (par défaut : 7935)
    </Note>

    <Warning>
 **Pour les environnements de production**, nous recommandons une **Réserve** d'au moins 0.36 ETH pour prévenir les interruptions de service lors des pics de gas. Le montant de réserve plus élevé aide à maintenir la continuité du service pendant les périodes de prix de gas élevés sur le réseau. Il y a [un issue ouvert](https://github.com/livepeer/go-livepeer/issues/3744) pour réduire cette exigence à l'avenir.
    </Warning>

 Le minimum recommandé pour les tests est de 0.1 ETH.

 {/* To calculate the price your Gateway will pay for transcoding, divide the
 _Reserve_ amount by 100. In our example each payment will be 0.0003 ETH (0.03
 / 100) */}

 Au fur et à mesure que vous payez pour les services, le montant payé est soustrait de votre _Dépôt_, alors
 assurez-vous de surveiller le solde de votre _Dépôt_ et de le recharger pour maintenir les services
 de votre Gateway en fonctionnement.

    <div id="open-the-livepeer-cli">
    #### Ouvrir la CLI Livepeer
    </div>
 Suivez les instructions pour votre plateforme :
    <Tabs>
        <Tab title="Linux / Mac" icon="linux">
        ```bash icon="terminal" wrap lines
        livepeer_cli --host=localhost --http=7935
        ```
      </Tab>
      <Tab title="Docker" icon="docker">
        ```bash icon="terminal" wrap lines
        docker run -it --network host livepeer/go-livepeer:master livepeer_cli --host=localhost --http=7935
        ```
      </Tab>
      <Tab title="Windows" icon="windows">
        ```bash icon="terminal" wrap lines
        livepeer_cli.exe --host=localhost --http=7935
        ```
      </Tab>
    </Tabs>

    <div id="deposit-funds">
    #### Déposer les fonds
    </div>
 Choisissez **Option 11 : Invoquer "deposit broadcasting funds" (ETH)**

    - Entrez 0.065 pour le montant du **Dépôt** lorsque demandé.
    - Entrez 0.03 pour le montant de la **Réserve** lorsque demandé.

    <div id="verify-funds">
    #### Vérifier les fonds
    </div>
 Choisissez **Option 1 : Get node status** et confirmez que les montants corrects sont
 visibles.

 Vous devriez voir quelque chose comme ceci :
    ```bash icon="terminal" Wizard Stats
      +-----------------+
      |BROADCASTER STATS|
      +-----------------+
      Max Price Per Pixel    [your setting]
      Deposit               0.065 ETH
      Reserve               0.030 ETH
    ```
