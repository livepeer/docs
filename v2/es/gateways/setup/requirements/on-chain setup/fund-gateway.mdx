# Agregar fondos a la billetera del Gateway
</div>

Para operar el Gateway en producción, necesita tener Ethereum en la Blockchain L2 [Arbitrum One](https://arbitrum.io/) - que es donde están desplegados los contratos inteligentes de Livepeer y que proporciona la capa de pagos para Livepeer.

<Callout icon="question-circle" color="#2d9a67">
 ¿No es nativo de Web3?
  <Expandable title="Explicación rápida de Arbitrum">
 Cada blockchain opera como su propia red y utiliza su propia moneda.
 Ethereum es la moneda de la Red L1 de Ethereum y Arbitrum ETH es la
 moneda de la Red L2 de Arbitrum. Arbitrum es una solución de escalado para la
 red Ethereum - funciona agrupando transacciones y procesándolas
 fuera de cadena, para luego conciliarlas con la red principal de Ethereum, algo así como una
 tienda que suma todas sus ventas cada día y concilia sus recibos.
 Esto hace que las transacciones en Arbitrum sean mucho más baratas que en Ethereum, mientras
 que aún proporciona la seguridad y confianza de la red Ethereum.
  </Expandable>
</Callout>

<Info>
 _Si tiene ETH en la Red L2 de Arbitrum, simplemente puede transferir los fondos
 a la cuenta ETH del Gateway recién creada._
</Info>

  <StyledStep title="Puente a Arbitrum" titleSize="h2">
    <Info>
 _Livepeer se ejecuta en la Red L2 de Arbitrum y requiere que los fondos sean
 puenteados._
    </Info>
 Puede enviar ETH a su dirección de Gateway en Ethereum Mainnet y luego puentearlo a la Red L2 de Arbitrum.

 Vea la [Guía de puente de Arbitrum](https://docs.arbitrum.io/arbitrum-bridge/quickstart)

    <iframe src="https://docs.arbitrum.io/arbitrum-bridge/quickstart" height="600px" width="100%" title="Embedded content from docs.arbitrum.io" />

  <StyledStep title="Depositar en el Gateway" titleSize="h2">
 <Note>Puede hacer esto en el paso anterior simplemente enviando el Arbitrum ETH a su dirección de Gateway.</Note>

 Una vez que tenga ETH en la red Arbitrum, transfiéralo a su dirección de
 Gateway recién creada.

  </StyledStep>
  <StyledStep title="Configurar la reserva del Gateway y depositar fondos" titleSize="h2">
 Ahora necesitamos dividir los fondos del Gateway en un **Depósito** y una **Reserva**

    <Note>
 El proceso de depósito requiere:
    - Gateway ejecutándose en modo on-chain (no offchain)
    - Suficiente ETH en su billetera para el depósito + comisiones de gas
    - CLI conectada al puerto HTTP de su gateway (predeterminado: 7935)
    </Note>

    <Warning>
 **Para entornos de producción**, recomendamos una **Reserva** de al menos 0.36 ETH para prevenir interrupciones del servicio durante picos de gas. El monto mayor de reserva ayuda a mantener la continuidad del servicio durante períodos de precios altos de gas en la red. Hay [un issue abierto](https://github.com/livepeer/go-livepeer/issues/3744) para reducir este requisito en el futuro.
    </Warning>

 El mínimo recomendado para pruebas es 0.1 ETH.

 {/* To calculate the price your Gateway will pay for transcoding, divide the
 _Reserve_ amount by 100. In our example each payment will be 0.0003 ETH (0.03
 / 100) */}

 A medida que paga por los servicios, el monto pagado se resta de su _Depósito_, así
 que asegúrese de monitorear el saldo de su _Depósito_ y recargarlo para mantener los servicios
 de su Gateway en funcionamiento.

    <div id="open-the-livepeer-cli">
    #### Abrir la CLI de Livepeer
    </div>
 Siga las instrucciones para su plataforma:
    <Tabs>
        <Tab title="Linux / Mac" icon="linux">
        ```bash icon="terminal" wrap lines
        livepeer_cli --host=localhost --http=7935
        ```
      </Tab>
      <Tab title="Docker" icon="docker">
        ```bash icon="terminal" wrap lines
        docker run -it --network host livepeer/go-livepeer:master livepeer_cli --host=localhost --http=7935
        ```
      </Tab>
      <Tab title="Windows" icon="windows">
        ```bash icon="terminal" wrap lines
        livepeer_cli.exe --host=localhost --http=7935
        ```
      </Tab>
    </Tabs>

    <div id="deposit-funds">
    #### Depositar fondos
    </div>
 Elija **Opción 11: Invocar "deposit broadcasting funds" (ETH)**

    - Ingrese 0.065 para el monto del **Depósito** cuando se le solicite.
    - Ingrese 0.03 para el monto de la **Reserva** cuando se le solicite.

    <div id="verify-funds">
    #### Verificar fondos
    </div>
 Elija **Opción 1: Get node status** y confirme que los montos correctos son
 visibles.

 Debería ver algo como esto:
    ```bash icon="terminal" Wizard Stats
      +-----------------+
      |BROADCASTER STATS|
      +-----------------+
      Max Price Per Pixel    [your setting]
      Deposit               0.065 ETH
      Reserve               0.030 ETH
    ```
