The go-livepeer broadcaster node exposes an HTTP endpoint that accepts HLS segments and returns transcoded output. This is the core transcoding interface used by the Livepeer protocol: RTMP ingest, stream management, and VOD all ultimately submit segments through this path.

Applications that manage their own video pipeline (custom media servers, VOD pipelines with non-standard storage, or systems that pre-segment video) use the segment submission API directly.

<CustomDivider middleText="Broadcaster Mode" />

## Running a Broadcaster Gateway

A broadcaster gateway is a go-livepeer node running in broadcaster mode. It connects to the Livepeer network, selects orchestrators, manages probabilistic micropayment tickets, and submits segments for transcoding.

```bash
livepeer \
  -broadcaster \
  -network arbitrum-one-mainnet \
  -ethUrl <ARBITRUM_RPC_URL> \
  -ethKeystorePath /path/to/keystore \
  -maxPricePerUnit 0 \
  -rtmpAddr 127.0.0.1:1935 \
  -httpAddr 127.0.0.1:8935
```

With the broadcaster running, the local RTMP ingest at `rtmp://127.0.0.1:1935/stream/<streamName>` feeds into the transcoding pipeline. The go-livepeer broadcaster is part of the `livepeer/go-livepeer` repository.

Custom profiles can be specified via the RTMP webhook response. The webhook response body may include a `profiles` array and an optional `manifestID`:

```json
{
  "manifestID": "custom-stream-id",
  "profiles": [
    {
      "name": "custom-720p",
      "width": 1280,
      "height": 720,
      "bitrate": 3000000,
      "fps": 30,
      "profile": "H264Main"
    }
  ]
}
```

The bitrate field is in bits per second. The `gop` field sets GOP length in seconds; omitting it uses the encoder default.

## LPMS (Livepeer Media Server)

LPMS (`livepeer/lpms`) is a Go library that wraps FFmpeg to provide RTMP ingest, HLS output, and a GPU transcoding API. It is the foundation of the go-livepeer broadcaster's media handling and is available for embedding in custom Go media server applications.

LPMS accepts RTMP input on port 1935 and serves HLS output over HTTP:

```
rtmp://localhost:1935/stream/<id>   # RTMP ingest endpoint
http://localhost:7935/stream/<id>.m3u8  # HLS playback
```

LPMS requires libavcodec (FFmpeg) and friends. The `install_ffmpeg.sh` script in the repository installs dependencies to `~/compiled`.

For GPU transcoding, LPMS supports NVIDIA hardware via NVENC/NVDEC. Select GPU or software transcoding at runtime:

```bash
# software transcoding
go run cmd/transcoding/transcoding.go input.ts P720p30fps16x9,P360p30fps16x9 sw

# NVIDIA GPU 0
go run cmd/transcoding/transcoding.go input.ts P720p30fps16x9,P360p30fps16x9 nv 0
```

LPMS is most useful for Go applications building custom media server logic that needs to run alongside or independently of the Livepeer protocol network.
