The Livepeer AI Jobs API exposes eleven native pipelines through one consistent surface: HTTP POST against a gateway endpoint, JSON request body keyed by `model_id` and pipeline-specific fields, JSON response with the result and metadata. Real-time video AI runs separately through trickle streaming; this page covers the batch surface.
