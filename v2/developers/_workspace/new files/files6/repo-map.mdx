## Protocol and Node Infrastructure

<StyledTable variant="bordered">
  <thead>
    <TableRow header>
      <TableCell header>Repository</TableCell>
      <TableCell header>Language</TableCell>
      <TableCell header>Purpose</TableCell>
    </TableRow>
  </thead>
  <tbody>
    <TableRow>
      <TableCell>`livepeer/go-livepeer`</TableCell>
      <TableCell>Go</TableCell>
      <TableCell>Official protocol node. Implements gateway (broadcaster), orchestrator, and transcoder roles. Primary binary for network operators.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>`livepeer/protocol`</TableCell>
      <TableCell>Solidity</TableCell>
      <TableCell>On-chain protocol contracts: BondingManager, RoundsManager, TicketBroker, AIServiceRegistry, Controller. Deployed on Arbitrum One.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>`livepeer/lpms`</TableCell>
      <TableCell>Go</TableCell>
      <TableCell>Livepeer Media Server. Embeddable Go library wrapping FFmpeg for RTMP ingest, HLS output, and GPU-accelerated transcoding. Embedded inside go-livepeer.</TableCell>
    </TableRow>
  </tbody>
</StyledTable>

## AI Inference Stack

<StyledTable variant="bordered">
  <thead>
    <TableRow header>
      <TableCell header>Repository</TableCell>
      <TableCell header>Language</TableCell>
      <TableCell header>Purpose</TableCell>
    </TableRow>
  </thead>
  <tbody>
    <TableRow>
      <TableCell>`livepeer/ai-runner`</TableCell>
      <TableCell>Python</TableCell>
      <TableCell>AI inference container. Loads models into GPU, exposes pipeline REST API (text-to-image, audio-to-text, LLM, etc.). Deployed by orchestrators.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>`livepeer/comfystream`</TableCell>
      <TableCell>Python</TableCell>
      <TableCell>ComfyUI custom node for real-time video processing. Implements the live-video-to-video pipeline using ComfyUI workflows over the trickle protocol.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>`livepeer/pytrickle`</TableCell>
      <TableCell>Python</TableCell>
      <TableCell>Python SDK for building custom real-time processing services over the trickle protocol. Provides FrameProcessor and StreamServer abstractions.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>`livepeer/ComfyUI-Stream-Pack`</TableCell>
      <TableCell>Python</TableCell>
      <TableCell>Suite of custom ComfyUI nodes for live video and audio input. Includes LoadTensor and LoadAudioTensor nodes for streaming workflows.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>`j0sh/http-trickle`</TableCell>
      <TableCell>Go</TableCell>
      <TableCell>The trickle protocol implementation. HTTP/1.1-based streaming transport for sequential segment delivery. Dependency of pytrickle and go-livepeer.</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>`livepeer/livepeer-python-gateway`</TableCell>
      <TableCell>Python</TableCell>
      <TableCell>Reference Python gateway implementation. OrchestratorSession, PaymentSession, and LiveVideoJob classes for off-chain gateway clients.</TableCell>
    </TableRow>
  </tbody>
</StyledTable>
