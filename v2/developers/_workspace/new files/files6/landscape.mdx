The Livepeer ecosystem contains multiple software layers, each serving different integration needs. Understanding which layer you're working with determines which tools, SDKs, and documentation apply to you.

## Starting Points by Workload

**AI inference jobs (batch):** Start with the AI gateway API. The community gateway at `dream-gateway.livepeer.cloud` accepts unauthenticated requests. Install `@livepeer/ai` or `livepeer-ai` and call `generate.textToImage()` or whichever pipeline you need. No node operation, no ETH required.

**Live video (streaming and VOD):** Start with the Video REST API. Install `livepeer` (npm or pip), create a stream object, push RTMP from OBS or FFmpeg, serve the HLS playback URL. Add the `@livepeer/react` Player for browser playback.

**Real-time AI pipelines:** Start with ComfyStream. Build a ComfyUI workflow, install ComfyStream, connect it to a live stream. Register the instance as a BYOC container with an orchestrator when ready to go on-network.

**Custom inference containers:** Start with PyTrickle or a plain HTTP service that implements the BYOC container contract. Register in `aiModels.json` on a local orchestrator for testing.

**Protocol integration (governance, staking, clearinghouse):** Start with the contract addresses reference and the protocol repo. Most developer work does not require this layer.

<CustomDivider />

## Using the Network Without Running a Node

The large majority of developer use cases require no node operation and no ETH:

- Calling AI inference endpoints through the community gateway or a gateway provider
- Creating streams and uploading assets through the Video REST API
- Building playback and broadcast UI with `@livepeer/react`
- Testing real-time AI pipelines against the community gateway

Node operation (running a go-livepeer broadcaster or orchestrator) is relevant when: testing payment flows, building a production gateway with custom orchestrator routing, registering BYOC capabilities on-chain, or contributing to protocol-level infrastructure.

## Key Repositories

| Repository | Language | Purpose |
|---|---|---|
| `livepeer/go-livepeer` | Go | Protocol node: gateway, orchestrator, transcoder |
| `livepeer/ai-runner` | Python | AI inference container; exposes pipeline REST API |
| `livepeer/comfystream` | Python | Real-time ComfyUI video processing with trickle |
| `livepeer/pytrickle` | Python | Trickle protocol SDK for custom real-time pipelines |
| `livepeer/ComfyUI-Stream-Pack` | Python | ComfyUI custom nodes for live video input |
| `livepeer/ui-kit` | TypeScript | React Player and Broadcast components |
| `livepeer/livepeer-js` | TypeScript | Video REST API SDK |
| `livepeer/livepeer-python` | Python | Video REST API SDK |
| `livepeer/livepeer-ai-js` | TypeScript | AI gateway API SDK |
| `livepeer/livepeer-ai-python` | Python | AI gateway API SDK |
| `livepeer/protocol` | Solidity | On-chain protocol contracts |
| `livepeer/lpms` | Go | Livepeer Media Server (RTMP/HLS/transcoding library) |
