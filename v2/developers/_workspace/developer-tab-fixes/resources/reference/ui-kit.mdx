`@livepeer/react` provides composable React components for video playback and live broadcasting on Livepeer.

```bash
npm install @livepeer/react
```

Source: [`livepeer/ui-kit`](https://github.com/livepeer/ui-kit)

<CustomDivider />

## Player exports

Import from `@livepeer/react/player`:

| Component | Purpose |
|---|---|
| `Root` | Player root (accepts `src` array) |
| `Container` | Wraps video and controls |
| `Video` | Renders the `<video>` element |
| `Controls` | Control bar container |
| `PlayPauseTrigger` | Toggle play/pause |
| `PlayingIndicator` | Conditional render based on play state |
| `MuteTrigger` | Toggle mute |
| `Volume` / `VolumeIndicator` | Volume slider and indicator |
| `Seek` / `SeekBuffer` | Scrub bar and buffered range |
| `Time` | Current time / duration display |
| `FullscreenTrigger` / `FullscreenIndicator` | Fullscreen toggle and state |
| `PictureInPictureTrigger` | PiP toggle |
| `VideoQualitySelect` / `VideoQualitySelectItem` | Manual ABR quality override |
| `RateSelect` / `RateSelectItem` | Playback speed selection |
| `Poster` | Poster image before playback |
| `LiveIndicator` | Indicates live stream |
| `ClipTrigger` | Clip creation trigger |
| `LoadingIndicator` | Buffering state |
| `ErrorIndicator` | Error state |

## Broadcast exports

Import from `@livepeer/react/broadcast`:

| Component | Purpose |
|---|---|
| `Root` | Broadcast root (accepts `ingestUrl`) |
| `Container` | Wraps video preview and controls |
| `Video` | Local camera preview |
| `Controls` | Control bar container |
| `EnabledTrigger` / `EnabledIndicator` | Start/stop broadcast |
| `AudioEnabledTrigger` / `AudioEnabledIndicator` | Mic toggle |
| `VideoEnabledTrigger` / `VideoEnabledIndicator` | Camera toggle |
| `ScreenshareTrigger` / `ScreenshareIndicator` | Screen share toggle |
| `SourceSelect` | Camera/microphone device picker |
| `StatusIndicator` | Connection state display |

## Utility exports

Import from `@livepeer/react/external`:

| Export | Purpose |
|---|---|
| `getSrc(hlsUrl)` | Convert an HLS URL to a source array with WebRTC and HLS entries |

Import from `@livepeer/react/assets`:

| Export | Purpose |
|---|---|
| `PlayIcon`, `PauseIcon`, etc. | SVG icon components for player controls |
