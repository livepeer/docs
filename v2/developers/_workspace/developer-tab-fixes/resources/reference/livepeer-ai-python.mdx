The `livepeer` Python package covers the full Livepeer REST API and AI inference endpoints.

```bash
pip install livepeer
```

```python
from livepeer import Livepeer
from livepeer.models import components
import os

client = Livepeer(api_key=os.environ['LIVEPEER_API_KEY'])

# Text to image
result = client.generate.text_to_image(
    request=components.TextToImageParams(
        prompt='a mountain at dawn',
        model_id='SG161222/RealVisXL_V4.0_Lightning',
        width=1024,
        height=1024,
    )
)
# result.image_response.images[0].url

# Audio to text
with open('audio.mp3', 'rb') as f:
    transcription = client.generate.audio_to_text(
        request=components.BodyGenAudioToText(
            audio=components.Audio(content=f.read(), file_name='audio.mp3'),
            model_id='openai/whisper-large-v3',
        )
    )
# transcription.text_response.text
```

## Generate methods

| Method | Pipeline |
|---|---|
| `client.generate.text_to_image(request)` | text-to-image |
| `client.generate.image_to_image(request)` | image-to-image |
| `client.generate.image_to_video(request)` | image-to-video |
| `client.generate.image_to_text(request)` | image-to-text |
| `client.generate.audio_to_text(request)` | audio-to-text |
| `client.generate.text_to_speech(request)` | text-to-speech |
| `client.generate.upscale(request)` | upscale |
| `client.generate.segment_anything_2(request)` | segment-anything-2 |
| `client.generate.llm(request)` | LLM |

## Video methods

| Method | Resource |
|---|---|
| `client.stream.create(request)` | Create a livestream |
| `client.stream.get(stream_id)` | Get stream details |
| `client.asset.create(request)` | Create an asset (VOD upload) |
| `client.asset.get(asset_id)` | Get asset details |

## Error handling

```python
from livepeer.models import errors

try:
    result = client.generate.text_to_image(request=params)
except errors.HTTPValidationError as e:
    print('422 Validation:', e.detail)
except errors.HTTPError as e:
    if e.status_code == 503:
        print('Model loading; retry in 60s')
    else:
        raise
```
