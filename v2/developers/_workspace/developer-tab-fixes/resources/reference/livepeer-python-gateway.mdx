[`livepeer-python-gateway`](https://github.com/livepeer/livepeer-python-gateway) is a Python library for building custom Livepeer gateways. It provides typed interfaces for orchestrator discovery, session management, payment signing, and media transport.

```bash
pip install livepeer-gateway
# or: uv sync --extra examples
```

## Starting a session

```python
from livepeer_gateway.lv2v import start_lv2v, StartJobRequest

job = start_lv2v(
    orch_url="https://orch.example.com:8935",
    req=StartJobRequest(model_id="streamdiffusion-sdxl-v2v"),
    signer_url="https://signer.example.com",
    timeout=5.0,
)

# Publish input frames
media = job.start_media(config)
await media.publish_frame(frame_bytes)

# Subscribe to output frames
output = job.media_output(start_seq=-2)
async with output as o:
    async for packet in o.packets():
        process(packet)

# Background payments run automatically (every 5 seconds)
# Close when done
await job.close()
```

## Authentication modes

**On-chain (with signer):** Pass `signer_url` to `start_lv2v`. PaymentSession calls the remote signer for each PM ticket. The signer holds the ETH keystore.

**Off-chain (no signer):** Omit `signer_url`. PaymentSession uses the orchestrator's `auth_token` from `OrchestratorInfo`. No ETH signing involved.

**Token-based:** Pass a base64-encoded JSON `token` containing `orchestrators`, `signer`, `discovery`, and `signer_headers`. Token fields override keyword arguments.
