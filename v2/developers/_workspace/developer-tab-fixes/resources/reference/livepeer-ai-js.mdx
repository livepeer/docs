`@livepeer/ai` is the TypeScript SDK for AI inference on the Livepeer network. It wraps the AI gateway HTTP API with typed request and response interfaces.

```bash
npm install @livepeer/ai
```

```typescript
import Livepeer from '@livepeer/ai';

const client = new Livepeer({
  httpBearer: process.env.LIVEPEER_API_KEY,
  // Default gateway: https://dream-gateway.livepeer.cloud
});

const result = await client.generate.textToImage({
  prompt: 'a mountain at dawn',
  modelId: 'SG161222/RealVisXL_V4.0_Lightning',
});
// result.imageResponse.images[0].url
```

## Generate methods

| Method | Pipeline |
|---|---|
| `client.generate.textToImage(params)` | text-to-image |
| `client.generate.imageToImage(params)` | image-to-image |
| `client.generate.imageToVideo(params)` | image-to-video |
| `client.generate.imageToText(params)` | image-to-text |
| `client.generate.audioToText(params)` | audio-to-text |
| `client.generate.textToSpeech(params)` | text-to-speech |
| `client.generate.upscale(params)` | upscale |
| `client.generate.segmentAnything2(params)` | segment-anything-2 |
| `client.generate.llm(params)` | LLM (OpenAI-compatible) |

All methods return typed response objects. For the full parameter types, see the [AI pipelines](/v2/developers/build/ai-and-agents/ai-pipelines) page.

<CustomDivider />

## @livepeer/ai vs livepeer

`@livepeer/ai` covers AI inference only. The `livepeer` package covers the full REST API (streams, assets, webhooks, access control, and AI inference). Use `@livepeer/ai` when your application only needs inference. Use `livepeer` when you need video features alongside AI.
