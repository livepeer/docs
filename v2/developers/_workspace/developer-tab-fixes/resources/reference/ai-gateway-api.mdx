## Authentication

All endpoints accept an optional `Authorization: Bearer <key>` header. The community gateway (`dream-gateway.livepeer.cloud`) does not require authentication. Production gateways require an API key.

<CustomDivider />

## Error responses

| Status | Meaning |
|---|---|
| 400 | Malformed request body |
| 401 | Invalid or missing API key |
| 422 | Validation error (invalid model_id, missing required field) |
| 429 | Rate limit exceeded |
| 500 | Inference error on the orchestrator |
| 503 | Model is cold (loading); retry with backoff |

Error bodies include a `detail` field with the failure reason. For 422 errors, `detail` is an array of field-level validation errors.
