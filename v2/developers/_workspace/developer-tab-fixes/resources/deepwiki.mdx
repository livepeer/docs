[DeepWiki](https://deepwiki.com) is an AI-powered code exploration tool that indexes public GitHub repositories. The Livepeer repositories are indexed and queryable:

| Repository | DeepWiki URL | What it covers |
|---|---|---|
| `livepeer/go-livepeer` | [deepwiki.com/livepeer/go-livepeer](https://deepwiki.com/livepeer/go-livepeer) | Protocol node, broadcaster, orchestrator, payment, discovery |
| `livepeer/ai-runner` | [deepwiki.com/livepeer/ai-runner](https://deepwiki.com/livepeer/ai-runner) | AI inference runtime, pipeline implementations, model loading |
| `livepeer/comfystream` | [deepwiki.com/livepeer/comfystream](https://deepwiki.com/livepeer/comfystream) | Real-time AI video, ComfyUI integration, WebRTC transport |
| `livepeer/protocol` | [deepwiki.com/livepeer/protocol](https://deepwiki.com/livepeer/protocol) | Solidity contracts: BondingManager, TicketBroker, Minter |
| `livepeer/pytrickle` | [deepwiki.com/livepeer/pytrickle](https://deepwiki.com/livepeer/pytrickle) | Python trickle SDK, FrameProcessor, StreamServer |

<CustomDivider />

## Best use cases

DeepWiki is most useful for questions that require reading the actual implementation:

- "How does go-livepeer calculate the transcode score?"
- "What parameters does the ai-runner text-to-image pipeline accept beyond what the API docs list?"
- "How does TicketBroker validate a PM ticket on-chain?"
- "What is the default batch size in the ai-runner image pipeline?"

These questions require source code, not documentation. DeepWiki answers them by indexing and searching the code directly.

<CustomDivider />

## DeepWiki MCP

DeepWiki also provides an MCP server at `mcp.deepwiki.com/mcp`. Connect it to Claude Code or Cursor to query Livepeer source code from your editor:

```json
{
  "mcpServers": {
    "deepwiki": {
      "type": "url",
      "url": "https://mcp.deepwiki.com/mcp"
    }
  }
}
```
