  <Tip>start_lv2v selects an orchestrator, sends the initial payment, and returns a LiveVideoToVideo job object. Call job.media_output() to subscribe to the output stream and job.start_payment_sender() to begin background per-segment payments.</Tip>
</CenteredContainer>

The `lv2v` module (`livepeer_gateway.lv2v`) provides `start_lv2v` and the `LiveVideoToVideo` dataclass for managing live-video-to-video sessions against the Livepeer network.

<CustomDivider />

## start_lv2v

```python
from livepeer_gateway.lv2v import StartJobRequest, start_lv2v

job = start_lv2v(
    orch_url="https://orch.example.com:8935",
    req=StartJobRequest(model_id="streamdiffusion-sdxl-v2v"),
    signer_url="https://signer.example.com",
    timeout=5.0,
)
```

**Orchestrator selection precedence** (highest to lowest):
1. `token.orchestrators`
2. explicit `orch_url`
3. `token.discovery`
4. explicit `discovery_url`
5. signer-derived discovery endpoint

`start_lv2v` raises `NoOrchestratorAvailableError` if all candidates fail. It retries automatically through the full candidate list before raising.

## StartJobRequest

```python
@dataclass(frozen=True)
class StartJobRequest:
    request_id: Optional[str] = None   # gateway request ID for logging
    model_id: Optional[str] = None     # pipeline to run (required for start_lv2v)
    params: Optional[dict] = None      # initial pipeline parameters
    stream_id: Optional[str] = None    # stream ID for logging
```

`model_id` is required. Pass initial pipeline parameters in `params`; these are forwarded to the orchestrator's pipeline as the job's initial state.

## media_output()

```python
output = job.media_output(
    start_seq=-2,            # trickle start sequence (-2 = latest)
    max_retries=5,
    max_segment_bytes=None,
    connection_close=False,
    chunk_size=65536,
    max_segments=5,
    on_lag=LagPolicy.LATEST,
)

async with output as o:
    async for packet in o.packets():
        print(packet.kind, packet.pts_time, packet.size)
```

`media_output()` returns a `MediaOutput` configured against `job.subscribe_url`. It raises `LivepeerGatewayError` if `subscribe_url` is missing.

## Token-Based Auth

For managed deployments, all connection parameters can be bundled into a base64-encoded JSON token:

```python
import base64, json

token = base64.b64encode(json.dumps({
    "orchestrators": ["https://orch-1.example.com:8935"],
    "signer": "https://signer.example.com",
    "signer_headers": {"Authorization": "Bearer sk_xxx"},
    "discovery": "https://discovery.example.com",
}).encode()).decode()

job = start_lv2v(
    orch_url=None,
    req=StartJobRequest(model_id="streamdiffusion-sdxl-v2v"),
    token=token,
)
```

Token fields take precedence over keyword arguments. See the README token schema for all supported fields.
