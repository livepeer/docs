The Livepeer Data MCP is an MCP server that exposes Livepeer network data as queryable tools. It complements the [Livepeer Docs MCP](/v2/developers/build/ai-and-agents/ecosystem-mcp/docs-mcp) (which queries documentation) by providing live operational data.

<Note>
  The Livepeer Data MCP is planned but not yet publicly available. This page documents the intended design. Check the [Livepeer GitHub organisation](https://github.com/livepeer) for release status.
</Note>

<CustomDivider />

## Intended tool surface

The Data MCP is designed to expose:

| Tool | Description |
|---|---|
| `network_capabilities` | List all pipelines and models currently advertised by orchestrators |
| `orchestrator_stats` | Orchestrator count, stake distribution, active session count |
| `pipeline_availability` | Which models are warm, on which orchestrators, with current pricing |
| `pricing_snapshot` | Current per-pipeline pricing across the active orchestrator set |
| `network_health` | Aggregate metrics: total stake, active orchestrators, jobs processed |

These tools query the same data sources available at `tools.livepeer.cloud/ai/network-capabilities` and the Livepeer Explorer API.

<CustomDivider />

## Developer use cases

**Debugging:** "Which orchestrators have `flux-dev` warm right now?" answers whether a cold-model timeout is expected or indicates a network issue.

**Cost estimation:** "What is the current per-megapixel price for text-to-image?" informs production cost projections without leaving the editor.

**Capacity planning:** "How many orchestrators support `live-video-to-video`?" determines whether real-time AI workloads have sufficient network capacity.
