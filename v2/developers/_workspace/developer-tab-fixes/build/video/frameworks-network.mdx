[Frameworks](https://frameworks.network) is an open streaming stack built on the Livepeer network. It is referenced in the developer concepts as an alternative to the managed REST API for teams that want direct infrastructure access for video streaming workloads.

Frameworks provides a streaming layer that connects to Livepeer orchestrators for transcoding while giving the operator full control over ingest, routing, and delivery. This is relevant for teams building streaming platforms, broadcast infrastructure, or media tooling that need to customise the streaming pipeline beyond what the REST API exposes.

<CustomDivider />

## Frameworks vs REST API vs self-hosted gateway

| Path | Control | Complexity | Use case |
|---|---|---|---|
| REST API + SDKs | Low (managed) | Low | Application developers adding video features |
| Self-hosted gateway (go-livepeer) | High | Medium | Cost control, custom routing, data residency |
| Frameworks | High | High | Building a streaming platform or broadcast tooling |

Most developers use the REST API. Self-hosted gateways serve cost-sensitive or sovereignty-sensitive deployments. Frameworks serves teams building streaming infrastructure products.
