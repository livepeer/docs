The NaaP plugin registry is the distribution layer for plugins on the Livepeer network portal. Operators browse and install plugins through the Marketplace page at [operator.livepeer.org](https://operator.livepeer.org). Developers publish plugins through the `@naap/plugin-sdk` CLI.

<CustomDivider />

## Browsing plugins

The Marketplace page lists all published plugins with category tags, install counts, and compatibility information. Categories include: developer tools, governance, monitoring, analytics, and integrations.

Each plugin listing shows:
- Plugin name, description, and author
- Category and required permissions
- Version history and changelog
- Install button (one-click for portal operators)

<CustomDivider />

## Publishing a plugin

```bash
# Build the production bundle
naap-plugin build

# Publish to the registry
naap-plugin publish
```

The CLI validates the `plugin.json` manifest, builds the UMD bundle, and uploads it to the registry. Published plugins are available to all NaaP portal operators.

**Manifest requirements for publishing:**
- `id`: unique plugin identifier (lowercase, hyphens)
- `name`: display name
- `version`: semver version string
- `category`: one of `developer`, `governance`, `monitoring`, `analytics`, `integration`
- `permissions`: array of required shell permissions

<Note>
  The plugin registry is maintained at operator.livepeer.org. Full publishing documentation is at [operator.livepeer.org/docs/guides/publishing](https://operator.livepeer.org/docs/guides/publishing).
</Note>
