The community gateway at `dream-gateway.livepeer.cloud` is operated by the Cloud SPE. It provides free, unauthenticated access to all batch AI pipelines and the LLM endpoint for development purposes.

<CustomDivider />

## Using the community gateway

```bash
curl -X POST https://dream-gateway.livepeer.cloud/text-to-image \
  -H "Content-Type: application/json" \
  -d '{"prompt": "a mountain at dawn", "model_id": "SG161222/RealVisXL_V4.0_Lightning"}'
```

No API key, no account, no setup. The gateway routes to whichever orchestrator has the requested model warm.

The community gateway does not support `live-video-to-video` (real-time AI). Real-time pipelines require a self-hosted gateway or a provider that supports persistent stream connections.

## Moving to production

Switch from community to production by changing the base URL and adding an `Authorization` header:

```bash
# Development (community gateway)
curl -X POST https://dream-gateway.livepeer.cloud/text-to-image ...

# Production (managed gateway provider)
curl -X POST https://provider-gateway.example.com/text-to-image \
  -H "Authorization: Bearer $LIVEPEER_API_KEY" ...
```

The request body, response shape, and pipeline endpoints are identical. The only changes are the URL and the auth header.

See [self-hosted decision](/v2/developers/guides/gateways-as-developer/self-hosted-decision) for when self-hosting makes sense over a managed provider.
