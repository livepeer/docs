Livepeer provides two categories of viewership data: engagement metrics (view counts, watch time) and performance metrics (error rate, time to first frame, rebuffer ratio, exit-before-starts). Both are queryable by `playbackId` via the Livepeer API.

Data refreshes every 5 minutes. Newly uploaded assets take up to an hour before viewership data is available.

## Total Views

Query total view count for a `playbackId`. This endpoint accepts CORS-enabled API keys and can be called from the frontend:

```bash
curl https://livepeer.com/api/data/views/query/total/<playbackId> \
  -H "Authorization: Bearer <YOUR_API_KEY>"
```

Response:

```json
{
  "playbackId": "eaw4nk06ts2d0mzb",
  "dStorageUrl": null,
  "startViews": 142
}
```

## Creator Metrics

Query engagement and performance metrics across all your assets and streams. Requires a server-side API key:

```javascript
import { Livepeer } from 'livepeer';

const client = new Livepeer({ apiKey: process.env.LIVEPEER_API_KEY });

const metrics = await client.metrics.getCreatorViewership({
  playbackId: 'eaw4nk06ts2d0mzb',
  timeStep: 'day',
  breakdownBy: ['deviceType', 'continent'],
});
```

Breakdown dimensions include `deviceType`, `continent`, `country`, `subdivision`, `timezone`, and `viewerId`.

## Real-Time Metrics

Query live viewer count and error rate for an ongoing stream or VOD session. Requires `@livepeer/react` 4.2.0 or later for data collection:

```bash
curl "https://livepeer.com/api/data/views/now/<playbackId>" \
  -H "Authorization: Bearer <YOUR_API_KEY>"
```

Response:

```json
{
  "viewCount": 37,
  "errorRate": 0.02
}
```

`viewCount` is the number of active player sessions currently reporting heartbeats. `errorRate` is a decimal fraction (2% = 0.02).

## Filtering and Segmenting

The creator metrics API accepts filter and breakdown parameters:

| Parameter | Values | Description |
|---|---|---|
| `playbackId` | string | Filter to a specific asset or stream |
| `timeStep` | `hour`, `day`, `week`, `month`, `year` | Bucket size for time-series data |
| `breakdownBy` | `deviceType`, `continent`, `country`, `viewerId` | Dimensions to group by |
| `from` | ISO 8601 datetime | Start of time range |
| `to` | ISO 8601 datetime | End of time range |

Queries by dStorage ID (e.g. `ipfs://` or `ar://` URLs) return cross-account view metrics for all assets sharing that storage identifier. Queries by `playbackId` return metrics scoped to your account only.
