## Stub status codes (in each file's `{/* STATUS: ... */}` comment)

| Code | Meaning | Writer action |
|---|---|---|
| **STUB** | NET-NEW page with no existing source. Write from canonical sources named in the comment. | Write from canonical (no SME needed). |
| **REWRITE-STUB** | Source page exists at developers1 but has Studio refs or REVIEW: flags. The source path is named for reference; DO NOT copy verbatim. | Clean rewrite against canonical sources. |
| **MERGE-STUB** | Multiple sources combine into this page. Each source path + size listed in the comment. | Extract, dedupe, voice-pass into one page. |
| **SPLIT-STUB** | Single source splits into multiple targets. Source path + intended split listed. | Extract the relevant section. |
