Livepeer enables node operators to transcode video on GPUs while performing
other CUDA operations such as AI inference. As there is a very wide range of GPU
hardware out there, this document aims to crowdsource a list of specific GPU
models that have been tested and verified to work on Livepeer. If you've tested
an additional model, please submit an update to this document.

## Transcoding GPUs

- Livepeer supports transcoding on NVIDIA GPUs with NVENC/NVDEC. Any GPU
  [listed here](https://developer.nvidia.com/video-encode-and-decode-gpu-support-matrix-new)
  with those chips should theoretically work. Note that different models may be
  subject to different session limits that restrict the amount of video that can
  be transcoded.
- See
  [this document which lists tested driver versions](https://github.com/livepeer/go-livepeer/blob/master/doc/gpu.md)
  on the NVIDIA cards.
- **HEVC (H.265)** hardware encode/decode support is available on Maxwell Gen 2
  and later NVIDIA architectures. HEVC is increasingly important on the Livepeer
  network as it delivers better compression efficiency than H.264.

  HEVC ✅ = hardware encode **and** decode supported via NVENC/NVDEC. GTX 950
  (Maxwell Gen 2) supports HEVC encode only. All Pascal (GTX 10xx) and newer

  details see the [NVIDIA encode/decode support matrix](https://developer.nvidia.com/video-encode-and-decode-gpu-support-matrix-new).
</Note>

## AI Inference GPUs

AI workloads (Stable Diffusion, LLM inference, etc.) are primarily VRAM-bound.
The following GPUs are well-suited for running Livepeer AI pipelines:

| GPU Model                  | Architecture | VRAM   | Recommended Use Case                          |
| -------------------------- | ------------ | ------ | --------------------------------------------- |
| NVIDIA GeForce RTX 3090    | Ampere       | 24 GB  | Stable Diffusion, mid-size models             |
| NVIDIA GeForce RTX 4080    | Ada Lovelace | 16 GB  | Fast inference, good throughput               |
| NVIDIA GeForce RTX 4090    | Ada Lovelace | 24 GB  | Consumer best: Stable Diffusion, high batch   |
| NVIDIA RTX A4000           | Ampere       | 16 GB  | Reliable workstation GPU                      |
| NVIDIA RTX A6000           | Ampere       | 48 GB  | Large models, multi-modal inference           |
| NVIDIA L4                  | Ada Lovelace | 24 GB  | Efficient cloud inference (good perf/watt)    |
| NVIDIA L40S                | Ada Lovelace | 48 GB  | High-capacity cloud inference                 |
| NVIDIA A100 40GB / 80GB    | Ampere       | 40/80 GB | Enterprise: large-batch inference, fine-tuning |
| NVIDIA H100                | Hopper       | 80 GB  | Advanced model serving, highest throughput    |

<Tip>
  For AI workloads on Livepeer, ensure you have CUDA 12+, the NVIDIA Container
  Toolkit installed, and sufficient fast storage for model weights. Stake does
  **not** determine AI job routing — capability and price do. See the
  [hardware requirements page](./hardware-requirements) for full setup guidance.
</Tip>
