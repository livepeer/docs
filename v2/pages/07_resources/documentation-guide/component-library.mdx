# Component Library

Complete reference for all custom components in the Livepeer documentation.

<Note>
**Mintlify Global Components** are available without import: `Card`, `Icon`, `Steps`, `Tabs`, `Note`, `Warning`, `Accordion`, `Columns`, `CodeBlock`, `Badge`, `Tooltip`, and more.
</Note>

---

## How to Use

```jsx
import { YouTubeVideo } from "/snippets/components/display/video.jsx";
import { CustomCodeBlock } from "/snippets/components/content/code.jsx";
```
