The icon map is the canonical reference for choosing Font Awesome icons across navigation cards, tabs, accordions, callouts, and authoring tools.

Use it when a page or component needs an icon but the semantic choice is not obvious. Prefer page-type defaults first, then choose the most specific icon for the destination topic.

## Source Files

- Canonical authoring source: [`docs-guide/tooling/reference-maps/icon-map.mdx`](/docs-guide/tooling/reference-maps/icon-map)
- Shared data source: `snippets/data/reference-maps/icon-map.jsx`
- Audit command: `node operations/scripts/audits/content/reference/audit-icon-usage.js --md --verbose`

## Selection Rules

- Use `bolt` for quickstarts and fast-start actions.
- Use `rocket` for portal or launch surfaces.
- Use `server` for self-managed infrastructure and node deployment paths.
- Use `microchip` for orchestrator or GPU-backed compute runtime surfaces.
- Use `coins` for rewards, pricing, fees, funding, and protocol economics.
- Use `book`, `file-lines`, or `list-check` for guide, reference, and checklist surfaces.

## Maintenance

The map is data-backed so validators, authoring helpers, and documentation pages can share the same source. Update the data file first, then rerun the icon usage audit and refresh any generated reference pages.
