<Update label="This week" tags={["Live AI", "Trickle"]} description={<Subtitle variant="changelog">May 11 – 16, 2026</Subtitle>}>

### New features

- **Trickle `/next` endpoint for sequence probing** — Trickle channels now expose `GET /{channel}/next`, returning the next write sequence number alongside an `Lp-Trickle-Latest` header. Publishers and SDKs can call this before their first POST to align with the server's sequence numbering, eliminating a race that could drop the first segment on a fresh channel. The endpoint returns `404` for unknown channels and signals `Lp-Trickle-Closed: terminated` when a channel has been closed. This unblocks the new Python gateway SDK for [Live AI pipelines](/v2/developers/concepts/ai-on-livepeer).

</Update>

<Update label="May 7, 2026" tags={["Live AI", "BYOC", "Livepeer Box", "Bug Fixes"]} description={<Subtitle variant="changelog">May 2026</Subtitle>}>

### New features

- **Webcam input for Livepeer Box** - The Livepeer Box stream script now accepts a webcam (for example `/dev/video0`) as a video input source, in addition to video files. This makes it easier to test [Live AI pipelines](/v2/developers/concepts/ai-on-livepeer) end-to-end with a local camera.

### Updates

- **Auth tokens for BYOC worker registration** - BYOC orchestrators can now require an auth token when workers register, giving operators tighter control over which workers can join an orchestrator's BYOC capacity. See the [BYOC tutorial](/v2/gateways/guides/tutorials/tutorial-2-byoc-cpu-pipeline) for context on the BYOC architecture.
- **Live AI payment tracking events** - Live AI gateways now emit events when payments are sent to orchestrators, and surface delivery errors as a metric. This improves payment observability for gateway operators running Live AI workloads.

### Bug fixes

- **Fixed macOS prebuilt binaries** - Removed the X11 dependency from macOS builds so prebuilt binaries run again in environments without X11 installed. Mac users can now download and run releases without extra system libraries.

</Update>
