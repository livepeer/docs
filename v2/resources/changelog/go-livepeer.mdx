<Update label="Week of June 8, 2026" tags={["Live AI", "Remote Signer"]} description={<Subtitle variant="changelog">June 8 – 12, 2026</Subtitle>}>
  ## Week of June 8, 2026

### New features

- **Optional RTMP output for the AI media server** - Live AI gateway operators can now disable RTMP egress on the AI media server when it isn't needed — for example, when streams are delivered to viewers over WHEP instead of being republished as RTMP. Turning RTMP output off avoids spinning up an unused encode path, which reduces overhead for WHEP-only deployments. RTMP output remains enabled by default, so existing setups are unaffected. See the [AI pipelines guide](/v2/gateways/guides/node-pipelines/ai-pipelines) for Live AI gateway configuration.

### Updates

- **Optional auth webhook for remote signers** - Operators running a remote signer alongside a Live AI gateway can now point the signer at an external webhook to enforce policy checks before payments are signed. When configured, the signer forwards the incoming request headers and current signer state to the webhook URL and only proceeds with signing if the webhook returns a 200. Non-200 responses are propagated back to the caller with the upstream status code, making it straightforward to reject or rate-limit payment requests at the policy layer. Existing remote signer deployments are unaffected unless the new webhook URL is set. See the [remote signers guide](/v2/gateways/guides/payments-and-pricing/remote-signers) for setup details.

</Update>
