# Resource Hub Entry Point

The Resource Hub is the entry point for shared Livepeer reference material. Use it to find glossary pages, documentation guides, release notes, support resources, and operational references that apply across the docs.

This route is kept as the stable Resource Hub navigation target and redirects to the current portal route. The canonical destination is [Resource Hub Portal](/v2/resources/portal).
