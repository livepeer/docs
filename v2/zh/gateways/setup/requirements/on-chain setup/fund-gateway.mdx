# 向网关钱包添加资金

</div>

要在生产环境中运行网关，您需要在 [Arbitrum One](https://arbitrum.io/) L2 区块链上拥有 Ethereum——Livepeer 的智能合约部署在该链上，它也提供了 Livepeer 的支付层。

<Callout icon="question-circle" color="#2d9a67">
 不熟悉 Web3？
  <Expandable title="Arbitrum 快速说明">
 每个区块链作为其自身的网络运行，并使用其自身的货币。
 Ethereum 是 Ethereum L1 网络的货币，Arbitrum ETH 是 Arbitrum L2 网络的货币。Arbitrum 是 Ethereum 网络的扩展方案——它通过批量处理交易并在链下处理，然后与 Ethereum 主网进行对账，类似于商店每天汇总所有销售额并核对收据。
 这使得 Arbitrum 上的交易比 Ethereum 上便宜得多，同时仍然提供 Ethereum 网络的安全性和信任度。
  </Expandable>
</Callout>

<Info>
 _如果您在 Arbitrum L2 网络上已有 ETH，可以直接将资金转入新创建的网关 ETH 账户。_
</Info>

  <StyledStep title="桥接到 Arbitrum" titleSize="h2">
    <Info>
 _Livepeer 运行在 Arbitrum 的 L2 网络上，需要将资金进行桥接。_
    </Info>
 您可以将 ETH 发送到 Ethereum 主网上的网关地址，然后桥接到 Arbitrum 的 L2 网络。

 查看 [Arbitrum 桥接指南](https://docs.arbitrum.io/arbitrum-bridge/quickstart)

    <iframe src="https://docs.arbitrum.io/arbitrum-bridge/quickstart" height="600px" width="100%" title="Embedded content from docs.arbitrum.io" />

  <StyledStep title="存入网关" titleSize="h2">
 <Note>您可以在上一步中直接将 Arbitrum ETH 发送到网关地址来完成此操作。</Note>

 在 Arbitrum 网络上拥有 ETH 后，将其转入您新创建的网关地址。

  </StyledStep>
  <StyledStep title="设置网关储备金和存入资金" titleSize="h2">
 现在我们需要将网关资金分为**存款**和**储备金**

    <Note>
 存款流程要求：
    - 网关以链上模式运行（非离链模式）
    - 钱包中有足够的 ETH 用于存款 + gas 费用
    - CLI 已连接到网关的 HTTP 端口（默认：7935）
    </Note>

    <Warning>
 **对于生产环境**，我们建议**储备金**至少为 0.36 ETH，以防止在 gas 价格飙升时服务中断。较高的储备金额有助于在网络 gas 价格较高的时期维持服务连续性。有一个[开放的 issue](https://github.com/livepeer/go-livepeer/issues/3744) 计划在未来降低此要求。
    </Warning>

 测试的最低建议金额为 0.1 ETH。

 {/* To calculate the price your Gateway will pay for transcoding, divide the
 _Reserve_ amount by 100. In our example each payment will be 0.0003 ETH (0.03

 当您为服务付费时，支付的金额会从您的_存款_中扣除，因此请务必监控您的_存款_余额并及时充值，以保持网关服务的正常运行。

<div id="open-the-livepeer-cli">

    #### 打开 Livepeer CLI

</div>

 按照您的平台说明操作：
    <Tabs>
        <Tab title="Linux / Mac" icon="linux">
        ```bash icon="terminal" wrap lines
        livepeer_cli --host=localhost --http=7935
        ```
      </Tab>
      <Tab title="Docker" icon="docker">
        ```bash icon="terminal" wrap lines
        docker run -it --network host livepeer/go-livepeer:master livepeer_cli --host=localhost --http=7935
        ```
      </Tab>
      <Tab title="Windows" icon="windows">
        ```bash icon="terminal" wrap lines
        livepeer_cli.exe --host=localhost --http=7935
        ```
      </Tab>
    </Tabs>

<div id="deposit-funds">

    #### 存入资金

</div>

 选择 **Option 11: Invoke "deposit broadcasting funds" (ETH)**

    - 在提示时输入 0.065 作为**存款**金额。
    - 在提示时输入 0.03 作为**储备金**金额。

<div id="verify-funds">

    #### 验证资金

</div>

 选择 **Option 1: Get node status** 并确认显示的金额正确。

 您应该会看到类似以下内容：
    ```bash icon="terminal" Wizard Stats
      +-----------------+
      |BROADCASTER STATS|
      +-----------------+
      Max Price Per Pixel    [your setting]
      Deposit               0.065 ETH
      Reserve               0.030 ETH
    ```
